# Игра мемов

Браузерная 3D-игра: персонаж входит в комнату с тремя картинками-порталами. Звучит мем — нужно провести персонажа в подходящую картинку.

## Запуск

Нужен Node.js 20 или новее. Устанавливать пакеты не требуется: библиотека, картинки и звуки уже в проекте.

```sh
node scripts/serve.mjs
```

Открыть адрес `http://127.0.0.1:4173`. Открытие `index.html` двойным щелчком не поддерживается: для модулей и загрузки звуков нужен HTTP-сервер.

## Правила

- 9 комнат и 3 жизни. Ошибка забирает одну жизнь.
- Правильный портал даёт 100 очков. За серию правильных ответов — бонус до 100 очков за комнату.
- Таймера нет. Звук можно повторять.
- Рекорд сохраняется в текущем браузере.
- 6 мемов: Bruh, Vine Boom / Скала, Among Us, металлическая труба, Anime Wow, Спанч Боб. Один и тот же звук не выпадает два раза подряд.

## Управление

| Действие | Управление |
| --- | --- |
| Двигать персонажа | WASD или стрелки |
| Подойти к картинке | Нажать на картинку или кнопку портала |
| Автоматически пройти к порталу | 1, 2, 3 |
| Повторить звук | Пробел или «Ещё раз» |
| Пауза | Esc |
| Телефон | Экранные стрелки или нажатие на портал |

Персонаж физически проходит к выбранной картинке; ответ засчитывается при входе в портал.

## Файлы

```text
dist/
  index.html     интерфейс
  style.css      адаптивное оформление
  app.js         звук, интерфейс, рекорды
  game.js        правила и движение
  scene.js       3D-комната и персонаж
  data.js        пары картинка / звук
  assets/        локальные картинки и MP3
  vendor/        Three.js r170 и его лицензия
scripts/
  serve.mjs      локальный HTTP-сервер
  check.mjs      проверка исходников и ресурсов
  download-assets.mjs  восстановление внешних ресурсов и SVG
tests/
  game.test.mjs  проверки правил, порталов и движения
```

## Проверки

```sh
node --test tests/game.test.mjs
node scripts/check.mjs
```

## Публикация

Игра — статический сайт. Для публикации на обычном хостинге загрузите содержимое `dist/`.

Для GitHub Pages можно использовать ветку `main` с папкой `/docs` (скопировав туда содержимое `dist/`) или собственную конфигурацию Pages с публикацией `dist/`. Автоматическая проверка проекта находится в `.github/workflows/check.yml`.

## Добавление мемов

Добавьте изображение и короткий звук в `dist/assets/`, затем пару в `dist/data.js`. Укажите уникальный `id`, название, пути к картинке и звуку. Игра сама выберет три разных варианта ответа. Реестр должен содержать минимум три мема.

Код проекта, процедурный персонаж и SVG-иллюстрации созданы для этой игры. Источники внешних ресурсов приведены в [ATTRIBUTION.md](ATTRIBUTION.md); права на сторонние мемы и записи принадлежат их правообладателям.
